§2 · MAIN RESULT · IN DEVELOPMENT Do We Click? 《夾唔夾》 building now

A real-time web game for 2–6 friends. Share one link, answer ten questions together, and the game measures how in sync your group is. Questions are generated from about 60 themed word banks and ~20 templates, so rounds rarely repeat. The interface works in Cantonese and English, and players in the same room can each pick their own language because answers are stored as item IDs, not text.

  1. Home: create or join a 4-digit room
  2. Lobby: share link, host starts
  3. Answer: 10–15 s per question
  4. Reveal: answers flip, formula shown
  5. Repeat ×10
  6. Your personal sync ranking
  7. Group score, title, share image

Lemma 3.1 (Flight Delay Forecasting). Ten years of aviation data predicts delay to within six minutes on average.

Jan – Feb 2026 · personal project · code ↗
  • Loaded ten years of U.S. Bureau of Transportation Statistics records (Aug 2013 – Aug 2023) into PostgreSQL and found delay patterns with window functions and aggregations.
  • Forecast each airline's average monthly delay at each airport. Trained on data up to Dec 2021 and tested on Jan 2022 – Aug 2023, so the model never sees the future.
  • Compared CatBoost, XGBoost and LightGBM; CatBoost won with MAE ≈ 5.8 min.
  • Built an interactive Streamlit app so anyone can query a forecast.
